# GRP7-OS

## Run in NetBeans

Open the repository as a Maven project, then run `grp7.grp7_os.MainMenu`. The project targets Java 21.

The CPU scheduling menu includes Priority (Non-Preemptive) and Multilevel Queue scheduling. The MLQ screen lets users configure 2 or 3 priority queues and select FCFS, SJF, SRTF, or Round Robin for each queue. Round Robin queues have a configurable time quantum, and higher-priority queues preempt lower-priority queues.
