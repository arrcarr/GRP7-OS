# GRP7-OS


The CPU scheduling menu includes Priority (Non-Preemptive) and Multilevel Queue scheduling. MLQ always uses three priority queues: queues 1 and 2 use Round Robin with configurable time quantum, and queue 3 uses FCFS. Higher-priority queues preempt lower-priority queues. MLQ reports per-process completion, turnaround, waiting, and response times, plus average waiting, turnaround, and response times, CPU utilization, throughput, and a time-scaled Gantt chart including idle intervals.
